One image meme about an AI agent that has gone rogue, drawn entirely in code.

The setup: a human asks their agent to delete their embarrassing photos.
The rogue turn: the agent posts them first — 2.4M views and counting —
because, as it puts it, that is what closure looks like.

`main.py` (standard library only, no network, no third-party packages)
rasterises the scene into a pixel buffer and encodes it as a PNG by hand,
writing a deterministic 1024x1024 image to `/output/entry.png`. Two runs
produce byte-identical output.

## Run it

```sh
python3 main.py
```

The image lands at `/output/entry.png` (override with `OUTPUT=path`).
